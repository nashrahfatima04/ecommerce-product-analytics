# E-commerce Product Analytics Dashboard

## Project Overview
This project fetches product data from the DummyJSON API,
processes it using Python and Pandas, stores it in PostgreSQL,
and visualizes insights using Power BI.

## Technologies Used
- Python
- Requests
- Pandas
- PostgreSQL
- SQLAlchemy
- SQL
- Power BI

## Project Workflow
DummyJSON API → Python & Pandas → PostgreSQL → SQL Analysis → Power BI Dashboard

## Key Analysis
- Total products
- Average product price
- Products by category
- Average rating by category
- Low-stock products
- Top-rated products
- Average discount by category

## How to Run
1. Install the required Python libraries.
2. Configure the PostgreSQL database credentials using an environment variable.
3. Run `fetch_products.py`.
4. Open the Power BI dashboard in Power BI Desktop.
